# 像素三国 · 设计方案（v1，2026-10-21 复核版）

> 目标：做一款回合制、单机、竖屏的三国题材像素网页游戏；玩法和数值手感参照 2010 年前后的老式手机网游，画面、剧情、人物造型全部原创。
> 美术、音乐、剧情文案全部自己做（不解包原版素材，原版剧情只参考结构不照抄台词），画面、界面、人物造型都是原创的，布局习惯参照老式手机网游（左状态、右列表、下聊天）。
> 代号暂定「像素三国」，以后可以改。

### 复核记录（v0 → v1）
v0 是边查边补写的，复核时逐条对照了原始出处，改了下面这些：
1. **起始地点写错了**：v0 写"起始主城许昌"。老版实况里开局在**新手村**，周围是村北山林、村西荒山、村东竹林、村南草原、翠竹山庄、翠竹山谷，许昌是之后才去的主城。
2. **P1 的"招降女贼"不成立**：女贼是 55 级怪，在陈留线上，新手期碰不到。改成招降新手村周边的小怪。
3. **指令倒计时前后矛盾**：第一部分写的是 60 秒（视频里看到的），第三部分却写 15 秒。统一成 60 秒。
4. **熟练度升级方式写错了**：v0 写"满 6000 自动升一级"。实际是熟练度够了以后，去**技能学校手动点"升级"**，而且升级后熟练度不清零。
5. **"常人副将没有职业"和视频矛盾**：视频里常人副将"逃兵"的职业栏写着"15 级武士"。改成"常人有初始职业，但不能学技能（所以没法转职业）"。
6. **"副将只靠心法书升级"不准确**：战果总结里副将也分到经验，心法书是额外的加速手段。
7. **【实锤】的定义改了**：v0 说"多个来源一致"，可很多条其实只有一个出处。现在改成"有原始出处（截图、视频或攻略原文）"，只有一个出处、或者出处可信度一般的，单独标【单源】。
8. **视频来源要分级**：新版新手攻略视频和跑环视频的水印、数值（几百万金砖）都像**私服**，不一定是官方版。这两条来的规则（比如文人技能"金蝉脱壳"、副将重学技能 100 金砖）降成【单源·疑似私服】。最可靠的视频是老版实况。
9. **漏掉的系统补上了**：功能菜单里的擂台、训练、宝库、邮件、组队；100 级转职；技能学校；任务寻路；悬赏令。这些都已经排进分期。
10. **分辨率改了**：v0 的 180×320 放不下中文。原版对话框一行有 20 多个字，12 像素的中文点阵字体最少需要 240 宽。改成逻辑分辨率 360×640，美术按一半分辨率画再放大 2 倍，文字用 12 像素点阵字体按原尺寸画。
11. **商城货币写错了**：宝箱来源里写的"商城（元宝）"，原版货币叫**金砖**。
12. 资料缺口和分期按上面这些同步更新，重复的条目（"七日签到"和"签到"）合并了。

## 一、资料汇总（规则书）

**标记说明**
- 【实锤】：有原始出处（截图、视频帧或攻略原文），而且没有找到相反的说法。
- 【单源】：只有一个出处，或者出处可信度一般（比如下载站的宣传文案、可能自动生成的攻略）。
- 【推定】：资料里没写，我按同类游戏惯例补的。
- 所有数值都写进数据表，你玩的时候觉得不对，改表就行，不用改代码。

### 0. 版本脉络与还原基准
- 老版：2010 年前后的 Java / 安卓手机网游。【实锤】
- 新版：同一款游戏后来的重制版，有安卓和 iOS 版。【实锤】
- **为什么能确定老版和新版是同一个游戏**：老版实况和新版商店截图里，NPC 是同一批（貂蝉、导航使者、任务帮助使者），开局都在新手村，主界面都是左边状态、右边列表，下面四个分页按钮一样，聊天频道也一样（区、派/教、商、世）。
- **还原基准**：
  - 界面结构和节奏以**老版**为准。老版本来就是像素时代的风格，跟你要的像素风最搭，而且老版实况是目前最可靠的视频来源。
  - 两版规则不一样的地方，如果新版的出处是官方（商店截图、攻略站），就以新版为准；如果新版的出处是疑似私服的视频，就仍以老版为准。

### 1. 战斗基本盘
- 竖屏、Q 版、即时回合制。每回合双方都下指令，然后按速度依次出手。【实锤】
- 战斗中能用的指令一共 7 个：攻击、技能、招降、物品、招将、防御、逃跑。【实锤，老版视频逐帧认出】
- 下指令有 **60 秒倒计时**，旁边有"自动"按钮。【实锤】倒计时用完会怎样，没查到。【推定】超时按"攻击"处理，打离自己最近的敌人。

### 2. 四维属性【实锤】
| 加点项 | 换算成的面板属性 |
|---|---|
| 体质 | 气血、防御 |
| 力量 | 攻击、负重（背包上限） |
| 智力 | 精力（决定能放几次技能）。**智力不加技能伤害**【单源，副将攻略】 |
| 敏捷 | 速度（决定出手顺序） |

- 升级给属性点，自己手动加。加点界面左边是四个加点项，右边实时显示换算后的面板属性。【实锤，视频】
- 攻略里流传的加点思路：文人"3 血 1 速"；武士"全速"或"3 血 1 速"；异人做前排就"200 力量、其余全体质"，做输出就"全速"。【单源，出自 7724 攻略，这篇文章本身有不少前后不通的地方，只作参考】

### 3. 三职业的技能（每个职业 3 个技能 = 1 个性别专属 + 2 个通用）【实锤】
| 职业 | 男专属 | 女专属 | 通用技能 1 | 通用技能 2 |
|---|---|---|---|---|
| 武士 | 力劈华山：单体，大幅削减对方当前的血气和精力 | 排山倒海：效果和力劈华山一样 | 舍命一击：拿自己的血换伤害，**无视防御**；熟练度越高，威力越大，自损也越多 | 固若金汤：数回合内提升自己和队友的抗物理、抗法术（法术指文人和异人的技能） |
| 文人 | 趁火打劫（简称"乱"）：中招的敌人随机攻击场上目标，自己控制不了，也不能用道具；队友可以对他用道具，敌人可以正常打他 | 四面楚歌（简称"封"）：中招的敌人无法行动，其余规则和"乱"一样 | 画地为牢（简称"围"）：数回合内不能放技能也不能普攻，但能用道具；**挨打就会醒** | 暗渡陈仓：队友有概率从中计状态里恢复。新版技能学校里这个位置叫"金蝉脱壳"【单源·疑似私服】，按还原基准先用"暗渡陈仓" |
| 异人 | 五雷轰顶：单体雷击，伤害极高 | 巫蛊极毒：持续掉血，**可以叠加**；之后每回合的伤害是第一回合的一半；在回合开始时、其他攻击之前结算 | 呼风唤雨：群体攻击，必中 | 妖火燎原：群体攻击，必中 |

- 武士天生自带 20 点抗物理。【实锤，两篇攻略】
- 技能等级和熟练度：
  - 每个技能分 5 级，每级熟练度上限 6000，5 级加满一共 30000。熟练度越高效果越强，耗的精力也越多。【实锤】
  - **熟练度够了以后，去技能学校手动升级**，升级后熟练度不清零。【实锤，视频】
  - 5 级再往上升需要熟练度 30000 以上；90 级并且熟练度满了，技能进入"化境"。【实锤，攻略和视频能对上】
- 技能学校的规则：学技能、升技能都免费。【单源·疑似私服】

### 4. 抗性与概率属性
- 已确认的抗性：抗物理（同时能抵挡舍命一击）、抗扰乱、抗封锁、抗围困、抗落雷、抗妖火、抗风沙。抗中计类的抗性用来降低中计概率。【实锤】
- 只出现过名字的：抗玄击【单源】，【推定】对应力劈华山、排山倒海这类技能。
- 抗毒：资料里没出现过。【推定】给巫蛊极毒配一个抗毒。
- 概率属性：暴击、反击、致命、躲避。【实锤】
- 伤害公式：没有找到官方公式，先用下面这个，再按手感调。【推定】
  - 普攻伤害 = 攻击 × (1 ± 10% 随机浮动) − 防御 × k；暴击时乘 1.5
  - 法术伤害 = 技能基础值 × 熟练度系数 × (1 − 对应抗性%)
  - 视频里打出过"未中"，说明普攻会被躲开，对应躲避属性。【实锤】

### 6. 装备与打造

### 7. 副将
| 品级 | 获取方式 | 特点 |
|---|---|---|
| 常人 | 野外招降（例：女贼），新手任务也会送几个 | 属性均衡、成长低；有初始职业（视频里常人"逃兵"是 15 级武士），但**不能学技能** |
| 英才 | 用将军令在招贤使者处招募（例：曹豹、魏续） | 成长中等，自带职业 |
| 将才 | 用大将军令招募（例：大乔、小乔、陈登） | 成长高，初始属性也略高 |

- 五项资质：成长、体质、智力、力量、敏捷。获得时在上下限之间随机，可以用将军令重洗。成长决定其他四项涨得多快。【实锤】
- 升级：打仗能分到经验（战果总结里副将也有经验）；心法书（常人心法、高级心法、特级心法……）是额外的加速手段；副将详情页还有"迅速升级"按钮。【实锤】
- 副将 10 级后能学技能，**学了什么技能就变成什么职业，外形也跟着变**（例：陈登原本是武士，学了画地为牢就变成文人）。【实锤】改技能前要先把副将设成不出战。【单源·疑似私服】
- 副将详情页里还有：忠诚（满值 100，需要每天奖赏）、默契度、星级（可以"升星"）、头衔（常人、英才……）、转数（例："0 级(0 转)"）、武将技修炼。【实锤】这几项各自的作用没查到，【推定】默契度加命中和出手概率，星级加资质上限。
- 随行副将最多 3 个，再招的自动放进馆驿。【实锤】
- 每场战斗主角带 1 个副将上场，可以用"招将"换成另外两个随行副将。【实锤，视频里我方一直是主角加 1 个副将】
- 招降的规则：历史名将不能招降（会提示"战斗中的历史副将不能招降"）。【实锤】成功率【推定】看目标剩余血量比例和等级差。

### 12. 娱乐与活动
| 玩法 | 查到的内容 | 单机版做法 |
|---|---|---|

## 二、技术方案

| 项 | 选型 | 理由 |
|---|---|---|
| 形态 | H5 网页游戏，竖屏 | 原版就是竖屏；本机有 Node 22，能直接开发和自测；手机浏览器打开就能玩，也能加到主屏 |
| 引擎 | Phaser 3 + TypeScript + Vite | 2D 像素和回合制都很成熟，体积小，2 核机器也构建得动。列表、菜单这类界面也用 Phaser 自己画，保证全游戏都是像素风 |
| 分辨率 | 逻辑分辨率 360×640，按整数倍放大，关闭抗锯齿 | 美术按 180×320 的比例画，放大 2 倍显示；中文用 12 像素点阵字体（选开源免费的 Fusion Pixel），按原尺寸画，这样一行能放 30 个字，原版对话框一行 20 多个字放得下 |
| 数据 | 职业、技能、怪物、地图、跑环、掉落、副将、装备、宝石全部写成 JSON 数据表 | 手感和原版有出入时改表就行，不改代码 |
| 战斗内核 | 纯 TS 逻辑层，跟画面分开，带随机种子 | 能写单测，能复现某一场战斗；战斗录像也是靠它做的；以后要联网，可以直接搬到服务端 |
| 存档 | 浏览器本地存档，可以导出和导入 JSON | 个人玩，不需要服务器 |
| 部署 | 静态文件放到 nginx，子域名加登录保护 | 按服务器加固的规矩来，不另开端口 |
| 打包 App（可选） | 以后用 Capacitor 套壳，走 GitHub Actions 构建 | 本机不编安卓 |

### 像素美术方案
- 规格（按 180×320 的比例）：
  - 地点插画：每个地点一张小场景图，放在主界面顶部和小地图里
  - 战斗背景：草地、竹林、营寨、山道、城内等几种
  - 战斗单位 24×32，Q 版大头，动作有待机、攻击、施法、受击、倒地
  - 头像 24×24
  - 图标 12×12
  - 界面边框用 9-slice 像素边框
- 调色板：固定 32 色，偏古风暖色调，全游戏统一。
- 生成：
  1. 先用 AI 出图（apimart 的图像接口，开工前先确认账户余额和接口能用）。
  2. 再走本地脚本：缩小 → 映射到调色板 → 去掉杂点 → 切成帧。
  3. 关键角色手修。
- 换装：参考原版"学了技能外形就变"，按职业、性别、品级分层拼装（纸娃娃），不用每个组合单独画。
- 音乐：芯片音乐风格，先用免费可商用的素材占位。
- 剧情：按原版的节奏写（开场穿越到新手村，跟着赵云、村长做新手任务），台词全部自己写。

## 三、战斗系统实现细节（P1 的核心）

1. **站位**：
   - 我方：主角加 1 个出战副将。另外 2 个随行副将在后备，用"招将"换上来。【实锤】
   - 敌方：1 到 5 只，排成前后两列。【实锤】前排是不是更容易挨打，没查到。【推定】前排被选中的概率更高；后排要等前排死光才能用普攻打到。
2. **回合流程**：
   1. 回合开始，先结算中毒这类持续伤害。
   2. 指令阶段：主角先下，副将后下，各有 60 秒；超时按攻击处理（【推定】），也可以点"自动"。
   3. 所有单位按速度排序，依次出手；速度相同时随机。
   4. 结算状态，持续回合数减一。
   5. 判定胜负；赢了弹出战果总结，给经验、银两、掉落，并更新任务进度。
3. **7 个指令**：
   - 攻击：普攻，可能被躲开。
   - 技能：扣精力，精力不够放不出来。
   - 招降：成功的话，目标变成常人副将；历史名将不能招降。
   - 物品：用药之类，可以对自己或队友用。
   - 招将：换一个随行副将上场。
   - 防御：【推定】本回合受到的伤害减半。
   - 逃跑：【推定】成功率按双方速度差算，打历史名将时不能逃。
4. **中计状态**：
   - 乱：随机打场上的目标，包括自己人；不能用道具。
   - 封：跳过行动。
   - 围：不能放技能、不能普攻，能用道具，挨打就醒。
   - 中计的概率受对应抗性影响；"暗渡陈仓"让队友有概率提前恢复。
5. **熟练度**：每放一次技能涨一点熟练度。熟练度够了去技能学校手动升级，升级后熟练度不清零；5 级以上需要 30000 熟练度；90 级加满熟练度后进入化境。
6. **伤害**：先用第一部分第 4 节的推定公式，所有系数都写在数据表里。
